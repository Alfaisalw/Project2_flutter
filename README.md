# Tuwaiq Academy App 🚀

A comprehensive and interactive mobile application designed to explore educational bootcamps and programs offered by **Tuwaiq Academy**. The app provides a seamless user experience for browsing tech domains, viewing program statuses, and reading detailed course objectives.

## 📌 Core Features
* **Explore Categories:** Browse through various tech domains and main fields easily.
* **Bootcamps & Initiatives:** View available programs with real-time registration status (Open/Closed).
* **Detailed Insights:** Access comprehensive details for each bootcamp, including the description, goals, and requirements.

## ✨ Additional Features & Technical Highlights
* **Modular Custom Widgets:** Designed reusable custom widgets to maintain clean architecture, reduce code duplication, and ensure a consistent UI across the app.
* **Horizontal Scrolling Navigation:** Implemented a smooth horizontal scroll (Carousel style) for an intuitive and modern category browsing experience.
* **Interactive UI/UX:** Utilized modern Flutter widgets like `ExpansionTile` (Accordion UI) for an elegant and space-saving reading experience.
* **Asynchronous Data Handling:** Smooth integration of RESTful APIs using `FutureBuilder` with customized loading states.
